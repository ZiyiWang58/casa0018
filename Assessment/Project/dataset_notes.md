# Dataset Notes

## Initial classes
- plastic_bottle
- can
- general_waste

## Dataset plan
This project will primarily use a self-collected image dataset captured with a smartphone camera.

## Data collection goals
- Capture multiple examples for each class
- Use different backgrounds, lighting conditions, distances and angles
- Include realistic cluttered environments
- Keep class balance as much as possible

## Risks
- Some waste categories may be visually ambiguous
- Lighting and background may affect performance
- Similar shapes or reflective surfaces may confuse the classifier
